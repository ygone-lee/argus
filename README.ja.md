Argus は、開いている Claude Code のセッションをすべて見張るローカルの Web ボードです。ターミナル・プロジェクト・
git worktree をまたいで、1 セッション 1 列で横に並べて表示します。名前は、すべての目を同時に閉じることのなかった
ギリシャ神話の百眼の巨人に由来します。

Claude Code の使い方は今までどおりです。Argus は Claude Code 自身のフックを通じて状況を受け取り、Mac 上の小さな
SQLite データベースに記録し、**http://127.0.0.1:7799** でページを提供します。どのセッションが何をしているか、
どれがあなたを待っているか、最後に何と答えたかが一目でわかり、正しいターミナルタブを探さずにそのまま返信できます。

> **Claude Code だけで動きます — 必要なのは Claude のサブスクリプションだけ。** Argus は Anthropic API を呼び出さず、
> API キーも求めません。ボード自体はモデルを一切呼び出しません。Claude を使う機能(ブレイン・日次ログ・カードチャット)は
> すべて、すでにログインしている `claude` CLI を通るので、Claude Code と同じプランの範囲で動きます。

## なぜ作ったか

複数の Claude Code セッションを並行して動かすと(リポジトリごと、worktree ごと、タスクごと)、すぐに追いきれなくなります。

- **どのセッションが何をしたか?** ターミナルのタブはどれも同じに見え、何を頼んだかをスクロールして探すのは手間です。
- **どこまで進んでいたか?** しばらく離れると、どれが終わってどれがまだ動いているのか、最後の答えが何だったのかがわかりません。
- **返事の見逃し。** 別のタブを見ている間に、あるセッションが終わったり権限確認で止まったりして、そのまま待ち続けます。
- **「次にやること」が頭の中にしかない。** まだ Claude に送る段階ではない、セッションごとの次の作業を置いておく場所がありません。

## できること

| | |
|---|---|
| 👀 **全部を一度に見る** | 1 セッション 1 列、最近のものから順に。プロジェクト・worktree・ブランチ・モデル・コンテキスト使用量つき。状態(*作業中*・*要確認*・*新しい応答*・*エラー*・*終了*)と、上部に状態ごとの件数。確認が必要になるとブラウザ通知と音でお知らせ。5 時間・週ごとの使用量バーと推奨ペース。 |
| 💬 **ターミナルを探さずに操作** | 返信(画像やドロップしたファイルパスも)、権限確認や質問への回答、作業の中断、名前の変更、このセッションだけのモデル・effort 変更、権限モード、巻き戻し、ブランチ・フォーク、スラッシュコマンド、セッションの終了。*Orca または tmux が必要です。* |
| 📝 **次にやることを管理** | セッションごとの「ネクストアクション」: Claude には送らないメモ、または今の返信が終わったら自動で送る予約。終了したセッションに残った TODO や、見落とした git 作業(未コミット・未プッシュ・PR のないブランチ)のレポート。 |
| 🔎 **話したことを何でも検索** | すべてのセッションのすべての質問と返答を全文検索(日本語・韓国語対応)。`argus-recall` スキルを使えば、どのセッションからでも Claude 自身が過去の会話を検索できます(「前回これどう直したっけ?」)。 |
| 🧾 **変更を確認** | セッションのフォルダごとの差分ビューア(未コミットの変更またはブランチ全体、統合・左右並び)。 |
| 📅 **振り返る** | 全セッションを時系列で並べたアクティビティと、毎朝書かれる日次の作業ログ(任意)。 |
| 🧠 **ブレインに頼む** *(任意)* | ボードを読める Claude Code セッションと会話:「何が私を待ってる?」「今日何をした?」「api セッションにテストを流すよう伝えて」。Slack や Gmail のメンションを受信箱のかんばんに集め、担当を提案し、カードをセッションに任せることもできます。 |

ボードの画面は 한국어・日本語・English に対応しています。ブラウザの言語に従い、⋮ → 🌐 で切り替えられます。

## クイックスタート

**必要なもの:** macOS、Claude アカウントでログインした [Claude Code](https://docs.anthropic.com/en/docs/claude-code)
(サブスクリプションプランで十分、API キー不要)、システムの Python 3(`/usr/bin/python3`、3.9 以上 — `pip install` するものはありません)、
最近のブラウザ(Chrome で確認済み)。

```sh
curl -fsSL https://raw.githubusercontent.com/ygone-lee/argus/main/install.sh | sh
```

Argus を `~/.argus` にダウンロードしてインストーラーを実行します。インストーラーは Claude Code に Argus のフックを追加し
(先に設定のバックアップを保存)、ボードを開くか尋ねます。同じコマンドをもう一度実行すると更新されます。

> **この Mac で開発ツールを使うのが初めてなら:** Argus には Apple の *Command Line Tools*(git と Python 3)が必要です。
> 入っていなければ、このコマンドがインストーラーを開きます。**インストール** を押して数分待ち、もう一度実行してください。

先に中身を見たい場合は [`install.sh`](install.sh)(約 40 行)を読むか、自分で clone してインストールできます。

```sh
git clone https://github.com/ygone-lee/argus.git
cd argus
/usr/bin/python3 install.py
```

あとは今までどおり Claude Code を使うだけです。開いているセッションは次の質問からボードに現れ、新しいセッションは
始まった時点で現れます。再起動後もフックがサーバーを自動で立ち上げます。

**まず見てみたいだけなら:** `/usr/bin/python3 demo/run.py` で、架空のプロジェクトとセッションが動く本物のボードが
http://127.0.0.1:7798 で開きます。専用の一時フォルダとポートを使い、あなたの Claude Code の設定には触れません。Ctrl+C で終了すると片付けます。

**任意の追加機能**

- **Orca または tmux** — セッションを Orca で、あるいは任意のターミナルアプリ(iTerm2、Ghostty、ターミナル.app …)の
  tmux の中で動かすと、ボードから返信・回答・操作ができます。なくても記録と表示はすべて行われ、iTerm2 やターミナル.app の
  タブを前面に出すことはできます。
- **Argus ブレイン** — Argus ロゴ横のブレインアイコンを押すか `B` キーで起動します。
- **コネクタ** — ⋮ → 🔌 コネクタで、Slack のメンション・DM と Gmail をブレインの受信箱に集めます。秘密情報は macOS のキーチェーンに保存されます。

**削除するには:** `/usr/bin/python3 ~/.argus/install.py --uninstall`(clone した場合はそのフォルダで `install.py --uninstall`)で
フックを外し、元のステータスラインに戻したあと、Argus のフォルダを削除してください。記録したデータは `~/.claude/session-log` に残ります。

## プライバシーと安全性

Argus は Claude Code の会話を保存するので、それを手元に置いたまま、邪魔をしないように作られています。

- **ローカルのみ。** サーバーは `127.0.0.1` でだけ待ち受け、`Host` ヘッダーを確認し、JSON のリクエストしか受け付けないので、
  ほかの Web ページから読み取ったり操作したりはできません。データはすべて `~/.claude/session-log`(SQLite とアップロード画像)にあります。
- **秘密情報は保存前に伏せます。** 既知のトークン形式(GitHub、Slack、Google、JWT)、`Bearer …`、URL 中のパスワード、
  `password=…` 形式の値は `[MASKED]` になります。それ以外は質問の中で `<private>…</private>` で囲めば、Claude には見え、Argus には `[private]` と保存されます。
- **隠れたモデル呼び出しも API キーもなし。** ボードの表示にトークンはかかりません。あなたが有効にしたり頼んだりした機能
  (日次ログ・ブレイン・カードチャット)だけが、あなた自身の Claude Code アカウントで Claude を動かします。
- **Claude Code 自体には手を加えません。** 会話記録を書き換えることはありません。`install.py` はほかのフックを残し、
  `settings.json` をバックアップし、`--uninstall` で元に戻します。フックが失敗しても Claude Code を止めません。
- **ターミナルへの入力は守られています。** セッションが確認待ちのとき、終了したとき、`claude` がそのターミナルの前面に
  いないとき、`!` で始まる文(シェルコマンドとして実行される)のときは入力しません。複数の手順を踏む操作は毎回画面を確認し、
  合わなければ Esc で取り消します。
- **コネクタは読み取り専用です。** Slack は読み取り権限だけ、Gmail とカレンダーは件名・差出人・時刻だけを読みます(本文は読みません)。

## 制限と FAQ

- **今のところ macOS のみ。** ターミナル操作・キーチェーン・Spotlight は macOS の機能です。
- **セッションの操作には Orca か tmux が必要です。** ほかのターミナルは前面に出せても入力はできません — tmux の中で Claude Code を
  動かせば、どのターミナルアプリからでも操作できます。対応ターミナルの追加は 1 ファイルです([Adding a terminal](docs/terminals.md))。
- **Claude Code の内部に合わせて動きます。** タイトル・要約・進行状況は会話記録ファイルから、ターミナル操作は画面から読み取ります。
  公開 API ではないためバージョンで変わることがあります。Claude Code 2.1.x で開発しています。更新後に動かなくなったら [issue](CONTRIBUTING.md) をお願いします。
- **Anthropic の API キーは必要?** 不要です。Claude が必要な処理はすべて `claude` CLI を通ります。
- **Claude の使用量を消費する?** ボードの表示では消費しません。日次ログ・ブレイン・カードチャットだけが、ほかの Claude Code の利用と同じくプランの使用量に数えられます。
- **VS Code や Claude デスクトップアプリのセッションは?** フックが動くセッションは記録されます。アプリを前面に出すことはできますが、入力はできません。

機能の詳しい説明、仕組み、拡張方法は [英語の README](README.md#feature-reference) を見てください。
