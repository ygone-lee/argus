# Argus 과거 대화 찾기

Argus 보드(127.0.0.1:7799)가 모든 세션의 요청·응답을 기록해 둔다. 이 세션 자신의 대화는 검색에서 빠진다.
검색은 기본으로 **지금 세션과 같은 프로젝트**(워크트리는 원래 저장소로 묶음)에서만 하고, 거기 없으면 모든 프로젝트로
넓혀 찾는다(결과 위에 어느 쪽인지 표시된다). 처음부터 다른 프로젝트까지 보려면 `--all`, 특정 프로젝트는 `--project 이름`.
명령은 하나씩 따로 실행한다(파이프·`&&` 로 묶지 않는다).

## 3단계로 좁힌다 — 필요한 만큼만 펼친다

1. **찾기**: 결과마다 턴 번호 `#tN`, 시각, 세션 제목, 프로젝트, 짧은 발췌가 나온다(관련도 순).
   ```
   ~/.claude/skills/argus-recall/recall search <단어…> [--all|--project 이름] [--me|--claude] [--recent] [--limit N]
   ```
   - 세 글자 이상 단어는 전문 색인으로, 두 글자 이하는 글자 일치로 찾는다. 단어는 모두 들어 있어야 하고(AND), 그런 턴이 없으면 일부만 맞는 결과를 관련도 순으로 보여 준다. 단어는 2~3개로 짧게.
   - 결과가 없으면 단어를 줄이거나 다른 표현(한국어·영어·코드 식별자)으로 다시 찾는다.
   - `--me` 는 사용자 요청에서만, `--claude` 는 응답에서만, `--recent` 는 최근 순.
2. **흐름 보기**: 고른 턴의 앞뒤(기본 3턴)를 같은 세션에서 짧게 본다.
   ```
   ~/.claude/skills/argus-recall/recall timeline #tN [앞뒤 턴 수]
   ```
3. **전문 보기**: 정말 필요한 턴만 전문을 읽는다(중간 메시지 포함, 6000자 넘으면 `--full`).
   ```
   ~/.claude/skills/argus-recall/recall turn #tN [--full]
   ```

## 답할 때

- 찾은 내용은 "언제·어느 세션(제목·프로젝트)·#tN" 을 밝혀 인용한다. 기록은 그 당시 기준이므로 지금 코드·상태와 다를 수 있다 — 파일·함수·설정을 근거로 쓰기 전에 지금 상태를 확인한다.
- 기록의 `[MASKED]`(자동으로 가린 비밀값)·`[private]`(사용자가 `<private>` 로 감싸 기록에서 뺀 부분)는 복원하려 하지 않는다.
- 보드 서버에 연결하지 못하면 Argus 서버가 꺼져 있다는 뜻이다 — 사용자에게 알리고 넘어간다.
