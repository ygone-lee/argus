Argus 는 열어 둔 Claude Code 세션을 전부 지켜보는 로컬 웹 보드입니다. 터미널·프로젝트·git 워크트리를 가리지 않고,
세션 하나에 칸 하나씩 나란히 보여 줍니다. 이름은 눈을 한꺼번에 다 감은 적이 없다는 그리스 신화의 눈 백 개 달린 거인에서 왔습니다.

Claude Code 는 지금처럼 쓰시면 됩니다. Argus 는 Claude Code 자체의 훅으로 상황을 받아 Mac 안의 작은 SQLite 에 기록하고,
**http://127.0.0.1:7799** 에 페이지를 띄웁니다. 어느 세션이 무엇을 하는지, 어느 세션이 나를 기다리는지, 마지막에 뭐라고
답했는지 한눈에 보이고, 맞는 터미널 탭을 찾지 않고 바로 답할 수 있습니다.

> **Claude Code 만으로 돌아갑니다 — Claude 구독이면 충분합니다.** Argus 는 Anthropic API 를 부르지 않고 API 키도 요구하지
> 않습니다. 보드 자체는 모델을 전혀 부르지 않습니다. Claude 를 쓰는 기능(브레인·일일 업무 일지·카드 대화)은 모두 이미
> 로그인한 `claude` CLI 를 거치므로, Claude Code 와 같은 요금제 안에서 돌아갑니다.

## 왜 만들었나

Claude Code 세션을 여러 개 동시에 돌리면(저장소마다, 워크트리마다, 작업마다) 금세 따라가기 어려워집니다.

- **어느 세션이 뭘 했지?** 터미널 탭은 다 비슷해 보이고, 뭘 시켰는지 스크롤로 찾기는 번거롭습니다.
- **어디까지 했더라?** 잠깐 다른 일을 하고 오면 무엇이 끝났고 무엇이 아직 도는지, 마지막 답이 뭐였는지 알기 어렵습니다.
- **놓친 답변.** 다른 탭을 보는 사이 어떤 세션이 끝나거나 권한 확인에서 멈춰 그대로 기다립니다.
- **「다음에 할 일」이 머릿속에만 있다.** 아직 Claude 에게 보낼 때가 아닌, 세션별로 이어 할 일을 둘 곳이 없습니다.

## 빠른 시작

### 1. 준비물

- **macOS**
- **Claude Code** — Claude 계정으로 로그인한 상태(구독 요금제면 충분, API 키 불필요)
- **Python 3** — Mac 에 들어 있는 `/usr/bin/python3`(3.9 이상). `pip install` 할 것은 없고, 직접 부를 일도 없습니다(`ctl.sh` 가 안에서 씁니다)
- **tmux** — `brew install tmux`. 없으면 설치 프로그램이 설치할지 묻습니다
- **최신 브라우저** — Chrome 에서 확인했습니다

따로 설치할 것은 tmux 하나입니다. 세션·브레인·터미널이 보드 전용 tmux 서버에서 돌고 브라우저에 바로 보여서, 터미널 앱이 없어도 됩니다.

> **이 Mac 에서 개발 도구를 처음 쓰신다면:** Apple 의 *Command Line Tools*(git 과 Python 3)가 필요합니다.
> 없으면 아래 설치 명령이 설치 창을 띄웁니다. **설치** 를 누르고 몇 분 기다린 뒤 명령을 다시 실행하세요.

### 2. 설치

터미널에 아래 한 줄을 붙여 넣습니다.

```sh
curl -fsSL https://raw.githubusercontent.com/ygone-lee/argus/main/install.sh | sh
```

Argus 를 **`~/.argus`** 폴더에 내려받고 설치 프로그램을 실행합니다. 설치 프로그램은 Claude Code 설정(`~/.claude/settings.json`)을
먼저 백업한 뒤 Argus 훅을 넣습니다. 다른 훅과 설정은 그대로 둡니다. 설치 중에 아래 두 가지를 묻습니다.

| 묻는 것 | 「예」라고 하면 |
|---|---|
| tmux 가 없을 때: Homebrew 로 설치할까요? | `brew install tmux` 를 실행합니다. 「아니요」면 나중에 직접 설치하면 됩니다 |
| 지금 보드를 열까요? | 브라우저에서 http://127.0.0.1:7799 를 엽니다 |

이제 Claude Code 를 평소처럼 쓰면 됩니다. 열려 있던 세션은 다음 요청부터, 새 세션은 시작하자마자 보드에 나타납니다.
설치하기 전의 대화도 보드로 가져오려면 `~/.argus/ctl.sh backfill 7`(최근 7일)을 실행하세요.

무엇이 실행되는지 먼저 보고 싶다면 [`install.sh`](install.sh)(약 40줄)를 읽거나, 직접 clone 해서 설치해도 됩니다.

```sh
git clone https://github.com/ygone-lee/argus.git
cd argus
./ctl.sh install
```

> 이 문서의 명령에 나오는 `~/.argus` 는 curl 로 설치했을 때의 Argus 폴더입니다. clone 했다면 그 폴더 경로로 바꿔 쓰세요.

### 3. Mac 을 켰을 때

보드는 내 Mac 안에서 백그라운드로 도는 작은 서버(http://127.0.0.1:7799)입니다. 터미널을 닫아도 꺼지지 않습니다.
Mac 을 다시 켜면 아래 중 하나를 할 때까지는 꺼져 있습니다.

- **Claude Code 세션을 하나 시작한다.** 훅이 보드를 백그라운드로 띄웁니다.
- **`~/.argus/ctl.sh open` 을 실행한다.** 보드를 띄우고 브라우저로 엽니다(`start` 는 띄우기만).

> **예전 버전에 있던 「로그인할 때 자동 시작」은 당분간 없앴습니다.** macOS 가 로그인 때 띄운 서버는 개인정보 보호 때문에
> 다운로드·데스크탑·문서 폴더를 읽지 못해서, 보드로 끌어 놓은 파일을 찾지 못했습니다. 터미널이나 Claude Code 에서 띄우면
> 그 앱과 같은 권한을 갖습니다. 전에 켜 두었다면 다음 업데이트 때 로그인 항목이 저절로 지워지고, 지금 바로 지우려면
> `~/.argus/ctl.sh install` 을 실행하세요. 자동 시작은 Argus 를 Mac 앱으로 내놓은 뒤에 다시 넣을 예정입니다.

### 4. 자주 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| 보드 열기(꺼져 있으면 띄운 뒤 브라우저로 열기) | `~/.argus/ctl.sh open` |
| 보드가 돌고 있는지 보기 | `~/.argus/ctl.sh status` |
| 보드 끄기 · 다시 띄우기 | `~/.argus/ctl.sh stop` · `~/.argus/ctl.sh restart` |
| 설치 상태 점검(아무것도 바꾸지 않음) | `~/.argus/ctl.sh check` |
| 설치 전 대화 가져오기(기본 최근 7일) | `~/.argus/ctl.sh backfill 7` |
| 데모 보드 열기(지어낸 세션, 내 설정은 안 건드림) | `~/.argus/ctl.sh demo` |
| 업데이트 | 보드의 ⋮ → ⟳ 업데이트 확인, 또는 위 설치 명령(curl 한 줄)을 다시 실행 |
| 지우기 | `~/.argus/ctl.sh uninstall` 을 실행한 뒤 `~/.argus` 폴더 삭제 |
| 명령 전체 보기 | `~/.argus/ctl.sh help` |

보드가 뜨지 않으면 `~/.claude/session-log/server.log` 의 끝부분에 이유가 남습니다. 끄고 켜는 명령(stop·restart)은 보드 서버만 다시 띄웁니다.
보드 터미널에서 돌던 세션은 tmux 서버에 그대로 남습니다.

### 5. 업데이트

curl 한 줄로 설치했어도 `~/.argus` 는 GitHub 저장소를 받아 둔 것(git clone)이라, 업데이트는 GitHub 에서 새 변경을 받아(git pull) 옵니다.

- **알림:** 보드 서버가 몇 시간마다 GitHub 를 확인합니다. 새 버전이 있으면 보드 위에 「🎉 Argus 새 버전 v0.2.0 이 나왔습니다 · 바뀐 점 보기 · 업데이트 · 나중에」 띠가 뜨고,
  브라우저 알림도 한 번 보냅니다. 「나중에」를 누르면 그 버전은 다시 띄우지 않습니다.
- **받기:** 「업데이트」(또는 ⋮ → ⟳ 업데이트 확인)를 누르면 변경을 받고(fast-forward 만), 설치 프로그램을 다시 돌려 훅을 맞춘 뒤 보드를 다시 띄웁니다.
  보드 서버만 다시 뜨고 세션은 그대로입니다.
- **설정(⋮ → ⚙ 설정 → 업데이트):**

  | 항목 | 고를 수 있는 것 |
  |---|---|
  | 업데이트 방식 | **알림만**(기본) · **자동으로 받기** — 작업 중이거나 확인을 기다리는 세션이 없고 보드를 10분 넘게 쓰지 않을 때 받습니다. 받은 뒤 「✅ v0.2.0 으로 업데이트했습니다」 띠로 알려 줍니다 · **끔** |
  | 업데이트 채널 | **안정판(릴리스만)**(기본) — v0.2.0 같은 릴리스가 나왔을 때만 받습니다 · **최신판** — main 에 올라온 커밋을 모두 받습니다 |

커밋 안 한 변경이나 올리지 않은 커밋이 있는 폴더에서는 받지 않습니다(개발 중인 폴더를 덮어쓰지 않게). 같은 설치 명령(curl 한 줄)을 다시 실행해도 업데이트됩니다.

### 6. 처음 써 보기

1. 보드를 엽니다 — http://127.0.0.1:7799
2. 위쪽 **＋ 새 보드** → **✳ Claude Code** → 폴더 고르기 → **만들기**. 보드 터미널에 세션이 뜨고 칸이 생깁니다.
3. 칸 아래 입력창에 요청을 쓰고 Enter. 권한 확인과 질문도 칸에서 바로 답합니다.
4. 칸 머리의 **⌨ 터미널** 로 그 세션의 터미널을, **💬 대화** 로 대화 화면을 봅니다.
5. <kbd>?</kbd> 를 누르면 단축키 전체가 나옵니다 — <kbd>⌘</kbd><kbd>1</kbd>~<kbd>9</kbd> 칸 이동, <kbd>Z</kbd> 칸 크게 보기, <kbd>/</kbd> 대화 검색, <kbd>G</kbd> 빠른 이동 …

이미 다른 터미널에서 쓰던 세션은 그대로 보드에 나타납니다. 보드에서 답장까지 하려면 칸 ⋮ → **⇄ 보드 터미널로 가져오기** 를 누르세요.

**먼저 구경만 하고 싶다면:** `~/.argus/ctl.sh demo` 를 실행하면, 지어낸 프로젝트와 세션이 움직이는 진짜 보드가
http://127.0.0.1:7798 에 열립니다. 따로 쓰는 임시 폴더와 포트를 써서 내 Claude Code 설정은 건드리지 않고, Ctrl+C 로 끄면 정리됩니다.

## 새 보드: Claude Code · 터미널 · 마크다운

위쪽 **＋ 새 보드** 에서 세 가지 칸을 만듭니다. 셋 다 같은 보드 칸이라 맨 앞 고정, 끌어서 순서 바꾸기, ⌘숫자 이동,
<kbd>Z</kbd> 크게 보기, 보관이 똑같이 됩니다.

- **✳ Claude Code** — 고른 폴더에서 Claude Code 세션을 엽니다. 모델·effort·새 워크트리(`claude -w`)·첫 메시지를 고를 수 있습니다.
- **⌨ 터미널** — 고른 폴더에서 셸을 엽니다. 칸 자체가 터미널입니다.
  - 보드 tmux 서버에서 돌아서, 새로 고치거나 보드를 다시 띄워도 그대로 남습니다.
  - `exit` 하면 「↻ 같은 폴더에서 다시 열기」 버튼이 나옵니다.
  - 칸을 지우면 셸도 닫힙니다.
- **📝 마크다운** — 고른 폴더의 `.argus/boards/<이름>.md` 에 저장되는 문서입니다. 그 저장소의 `.git/info/exclude` 에 `.argus/` 를 넣어 커밋에 섞이지 않습니다.
  - **위쪽(문서):** ✎ 편집과 👁 보기를 오갑니다. 고치면 바로 저장됩니다. 보기에서 체크리스트(`- [ ]`)를 눌러 체크할 수 있습니다.
  - **아래쪽(AI 대화):** 「회의록 형식으로 정리해줘」처럼 요청하면 Claude 가 그 파일만 고칩니다. 다른 파일·명령·웹은 막혀 있습니다.
  - **되돌리기:** AI 가 고칠 때마다 답 아래 「되돌리기」로 고치기 전 내용으로 돌아갈 수 있습니다.
  - **모델:** ⋮ → ⚙ 설정 → 「마크다운 보드 AI 모델」(기본 Sonnet). 요청할 때마다 Claude 사용량이 듭니다.
  - 칸을 지워도 문서 파일은 폴더에 남습니다.

**선택 사항**

- **내 터미널 앱** — 없어도 됩니다. 직접 띄운 세션도 어디서 돌든 기록되고, 보드에서 답장·응답·조작까지 하려면 아무 터미널 앱(iTerm2, Ghostty,
  터미널.app …) 안의 tmux 에서 돌리면 됩니다. 이미 쓰고 있다면 Orca 도 됩니다. tmux 밖의 iTerm2·터미널.app 탭은 앞으로 가져올 수 있습니다.
- **보드 터미널** — ＋ 새 보드에서 만든 Claude Code 세션은 늘 보드 터미널에 뜹니다. 바깥 터미널 앱 없이, 칸은 대화 화면으로 열리고 필요할 때 칸 안에서 바로 터미널(xterm.js)을 씁니다. 보드 전용 tmux 서버(`tmux -L argus-web`)에서 돌아서 서버를 다시 띄워도 세션은 살아 있고, 칸 머리의 「⌨ 터미널 / 💬 대화」로 오갑니다. tmux 가 필요합니다.
- **터미널 패널** — 오른쪽 서랍(「터미널」 버튼, <kbd>`</kbd>, 터미널 안에서는 <kbd>⌃`</kbd>)에서 셸을 탭 여러 개로 씁니다. 탭은 보드 tmux 서버의 셸이라 새로고침·서버 재시작 뒤에도 남고, 탭에서 `claude` 를 띄우면 보드 세션 칸도 생깁니다. 브라우저에서 아무 명령이나 실행하는 기능이라 같은 출처·서버를 띄울 때마다 바뀌는 토큰이 있어야만 셸을 만들고 붙습니다.
- **tmux 세션도 칸 안에서** — 직접 쓰는 tmux 에서 도는 세션도 「⌨ 터미널」로 칸 안에서 열 수 있고, 어느 터미널 창에도 붙어 있지 않으면 「터미널로 이동」이 칸 안에서 엽니다. 보드용 묶음 세션으로 붙어서 다른 터미널의 화면은 그대로이고, 닫아도 tmux 세션은 계속 돕니다.
- **보드 터미널로 가져오기** — 다른 터미널(Orca·tmux·iTerm2 등)에서 도는 세션도 칸 ⋮ 메뉴의 「⇄ 보드 터미널로 가져오기」로 보드 터미널로 옮깁니다. 같은 세션 ID 로 이어 열어(`claude --resume`) 칸·넥스트 액션이 그대로 이어지고 모델·effort·권한 모드도 넘깁니다. Orca·tmux 는 보드가 종료(워크트리는 남김)까지 해 주고, 그 밖의 앱은 그 터미널에서 `/exit` 한 뒤 누르면 됩니다. 종료가 「백그라운드 작업이 돌고 있다」처럼 다른 것을 물으면 취소하고 그대로 둡니다.
- **브레인은 보드 터미널에서** — 고를 것 없이 늘 보드 터미널로 뜹니다(tmux 필요). 브레인 패널 안에서 「⌨ 터미널」로 브레인의 터미널을 열 수 있습니다.
- **Argus 브레인** — Argus 로고 옆 브레인 아이콘을 누르거나 `B` 를 눌러 시작합니다.
- **커넥터** — ⋮ → 🔌 커넥터에서 슬랙 멘션·DM 과 지메일을 브레인 인박스로 모읍니다. 비밀값은 macOS 키체인에 저장됩니다. 슬랙은 「Slack 앱 만들기」를 누르면 읽기 전용 앱 매니페스트가 채워진 Slack 화면이 열립니다: 워크스페이스 고르기 → Create → Install → User OAuth Token(xoxp-…) 복사해 붙여 넣기 — 저장·연결 확인까지 하고 이름도 워크스페이스 이름으로 붙입니다.

**지우려면:** `~/.argus/ctl.sh uninstall`(clone 했다면 그 폴더에서 `./ctl.sh uninstall`)로 훅을 빼고
원래 상태줄로 되돌립니다. 그다음 Argus 폴더를 지우세요. 기록한 데이터는 `~/.claude/session-log` 에 남습니다.

## 개인정보와 안전

Argus 는 Claude Code 대화를 저장하므로, 그 대화를 내 컴퓨터 안에 두고 작업을 방해하지 않도록 만들었습니다.

- **로컬 전용.** 서버는 `127.0.0.1` 에서만 열리고, `Host` 헤더를 확인하며 JSON 요청만 받으므로 다른 웹 페이지가 읽거나
  조작할 수 없습니다. 데이터는 모두 `~/.claude/session-log`(SQLite 와 올린 이미지)에 있습니다.
- **비밀값은 저장 전에 가립니다.** 알려진 토큰 형식(GitHub, Slack, Google, JWT), `Bearer …`, URL 속 비밀번호, `password=…`
  형태의 값은 `[MASKED]` 로 바뀝니다. 그 밖의 것은 요청에서 `<private>…</private>` 로 감싸면 Claude 는 보고 Argus 는 `[private]` 로 저장합니다.
- **숨은 모델 호출도, API 키도 없습니다.** 보드를 보는 데는 토큰이 들지 않습니다. 직접 켜거나 요청한 기능(업무 일지·브레인·카드 대화·마크다운 칸의 AI)만 내 Claude Code 계정으로 Claude 를 씁니다.
- **Claude Code 는 건드리지 않습니다.** 대화 기록을 고치지 않습니다. `install.py` 는 다른 훅을 그대로 두고 `settings.json` 을
  백업하며, `--uninstall` 로 되돌립니다. 훅이 실패해도 Claude Code 를 막지 않습니다.
- **터미널 입력은 안전장치를 거칩니다.** 세션이 확인을 기다릴 때, 끝났을 때, 그 터미널의 전면에 `claude` 가 없을 때는 입력하지 않습니다.
  `!` 로 시작하는 글(셸 명령으로 실행됨)은 보드 입력창에 직접 쳐서 바로 보낼 때만 받고, 예약 전송·브레인·인박스 맡기기로 온 것은 막습니다. 여러 단계를 밟는 조작은 단계마다 화면을 확인하고, 어긋나면 Esc 로 물립니다.
- **커넥터는 읽기 전용입니다.** 슬랙은 읽기 권한만, 지메일·캘린더는 제목·보낸 사람·시각만 읽습니다(본문은 읽지 않음).

## 한계와 자주 묻는 질문

- **아직은 macOS 전용입니다.** 터미널 조작·키체인·Spotlight 가 macOS 기능입니다.
- **세션 조작에는 tmux 가 필요합니다.** 보드에서 띄운 세션은 보드 전용 tmux 서버에서 돌고, 직접 띄운 세션은 tmux(아무 터미널 앱) 안이나
  Orca 에서 돌아야 조작할 수 있습니다. 그 밖의 터미널은 앞으로 가져오기만 되고 입력은 안 됩니다. 터미널 추가는 파일 하나입니다([Adding a terminal](docs/terminals.md)).
- **Claude Code 내부를 따라갑니다.** 제목·요약·진행 상황은 대화 기록 파일에서, 터미널 조작은 화면에서 읽습니다. 공개 API 가 아니라서
  버전에 따라 바뀔 수 있습니다. Claude Code 2.1.x 기준으로 개발합니다. 업데이트 뒤 문제가 생기면 [이슈](CONTRIBUTING.md)로 알려 주세요.
- **Anthropic API 키가 필요한가요?** 아니요. Claude 가 필요한 일은 모두 `claude` CLI 를 거칩니다.
- **Claude 사용량을 쓰나요?** 보드를 보는 데는 쓰지 않습니다. 업무 일지·브레인·카드 대화·마크다운 칸의 AI 만 다른 Claude Code 사용처럼 요금제 사용량에 잡힙니다.
- **VS Code 나 Claude 데스크톱 앱의 세션도 되나요?** 훅이 도는 세션은 기록됩니다. 앱을 앞으로 가져올 수는 있지만 입력은 안 됩니다.

기능 상세, 동작 방식, 확장 방법은 [영어 README](README.md#feature-reference) 를 보세요.
